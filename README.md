# Khaja Shaik — ServiceNow Developer Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript. Designed for deployment on Vercel from GitHub.

## Sections
- Introduction and professional focus
- Skills and CSA/CAD certifications
- Filterable project cards
- Experience and learning focus
- Contact links
- Responsive layout, subtle scroll reveal, and reduced-motion support

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Push this repository to GitHub.
2. Go to https://vercel.com/new and import the repository.
3. Choose the `Other` framework preset if prompted.
4. Leave Build Command and Output Directory blank for this static HTML project.
5. Deploy.

## Before publishing
- Verify all personal details and certification names.
- Update project statuses only when accurate.
- Replace placeholder project labels with links to real repositories once they exist.
- Do not publish employer-owned code, confidential details, credentials, or customer data.

## Tech
HTML, CSS, vanilla JavaScript. No build step or external dependencies.
